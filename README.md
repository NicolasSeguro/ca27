# CA27 — Casa Abierta 2027

Prototipos de sitio para Casa Abierta 2027, un encuentro de Hillsong Leadership Network en Buenos Aires (25 al 27 de febrero de 2027).

- `webs/`: índice y cuatro versiones (Inmersiva, Editorial, Manifiesto, Conferencia) sobre un sistema compartido en `webs/shared/ca27.css` y `ca27.js`.
- `MEMORIA.md`: datos del evento, reglas de marca y decisiones. Leer antes de tocar copy o diseño.
- `DOCS/` y `CA27_cursor/`: dirección estética y piezas de referencia. Los PSD no están en el repo (pesan más de 100 MB).

Para verlo en local, servir la raíz: `python3 -m http.server` y abrir `http://localhost:8000/webs/`. Abierto como archivo, Chrome no dibuja la firma.
